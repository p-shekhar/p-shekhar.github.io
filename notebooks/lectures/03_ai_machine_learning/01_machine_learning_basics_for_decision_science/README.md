# 01 Machine Learning Basics for Decision Science

This course will introduce predictive machine learning through the lens of decision support. It should stay grounded in tabular, operational, and business settings where model outputs affect prioritization, intervention, allocation, or risk management.

## Data Realism Standard

Simulated datasets in this course should look like operational decision data. Each example should make clear what a row represents, when features are observed, what outcome or structure is being predicted, and what action could follow from the model output.

The examples should avoid perfectly separable or overly clean patterns. Prefer multiple latent regimes, correlated features, nonlinear thresholds, noisy labels, drift, class imbalance, segment-level error differences, and resource constraints. Classic geometric datasets can be used briefly to teach algorithm behavior, but they should be paired with business-style tabular examples before drawing operational conclusions.
