# Lecture Notebooks

This directory is organized as professional lecture tracks.

## 00 Statistical Inference

Path: `00_statistical_inference/`

This track now groups two statistics courses under one umbrella:

- `00_stats_foundations_data_science/`
- `01_statistical_inference_for_decision_science/`

### 00 Statistical Foundations for Data Science

Path: `00_statistical_inference/00_stats_foundations_data_science/`

Direct notebook sequence covering statistical thinking for decision science, populations and data-generating processes, probability, sampling, simulation, estimation, interval estimation, hypothesis testing, effect sizes, exploratory analysis, regression, classification, model selection, and recommendation writing under uncertainty.

### 01 Statistical Inference for Decision Science

Path: `00_statistical_inference/01_statistical_inference_for_decision_science/`

Initialized notebook sequence covering formal inference, asymptotics, likelihood, interval estimation, testing, randomization inference, multiple testing, regression as an inferential engine, GLMs, hierarchical models, Bayesian updating, model checking, robustness, decision analysis, and stakeholder-facing reporting.
